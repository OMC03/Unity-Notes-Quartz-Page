# Link Play Setup

**NOTE: Before starting be sure your computer has the right specifications to allow for meta quest link play**

To get link play enabled you must first ensure you are on the same WIFI network as the PC you want to connect to if connecting wirelessly or have a lengthy USB-C cable that can connect you to the PC directly.

Press the meta/Oculus button on the right controller to pull up the apps menu from there head to settings and look for the tab on the left called "Link".

![[Link_Tab 1.png]]

If using a cable turn off "Use Air-Link (WIFI)". There should then be an option to connect to the desired PC using USB.

![[WIFI_Air_Link.png]]

After connecting to the PC you should be able to control it from the headset. This will confirm that Link Play is properly setup.
